## Two Pointers Identification process
### Consider 2-Pointers pattern when the following is present in question

1. Problem is of Arrays of LinkedList
2. Sorted or Sorting can help
3. Rearrangements of the elements of the Data structure is required
4. Asked to find pair/triplet/quadruplet
5. Detect Cycle in Linked List
6. Merge / Remove Duplicate is the ask
