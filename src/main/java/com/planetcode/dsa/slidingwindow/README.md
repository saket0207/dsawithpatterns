## Sliding Window Identification process
### Consider Sliding window when the following is present
    1. Questions has input in the form of Arrays / String
    2. Avoid if LinkedList
    3. Subarray or SubString is asked (not susequence becasuse its not contigous)
    
1. Max
2. Min
3. Longest
4. Shortest
5. Sum/ Count / Average
6. At most K / At least K

Windows can be of
1. Fixed size - Size of the window will be given by saying subarray / substring of K size or here target will be given which will match subarray/substring size
2. Variable size - Size will not be given but will be asked to find minimum / maximum length of subarray of substring. Here target will be given to that matches the sum of the sub array
